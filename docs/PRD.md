# PRD — HomeDesktop：跨平台手机式桌面启动器

> 版本：v1.1 ｜ 日期：2026-02-13 ｜ 状态：已确认（用户 2026-02-13 确认产品定位与技术栈；v1.1 澄清：**无独立"中控模式"，应用本身就是一张手机式桌面**）
> 文档按 skill `product-driven-project` 的 P1 阶段产出。

## 1. 项目背景与定位

**一句话定位**：一个跨平台、轻量、秒开的**手机式桌面**——像小米/安卓桌面（launcher）一样，在一张桌面上混排**图标 + 小组件**，应用、文件夹、小组件都通过**插件机制**添加到网格中。没有独立"模式"，这张桌面就是全部。

**参考与差异**：
- 参考小米/安卓桌面：图标网格 + 小组件混排、多页、文件夹、搜索。
- 参考 [WinLaunch](https://www.makeuseof.com/tag/enjoy-apples-launchpad-windows-machine-winlaunch/)（仿 macOS Launchpad）——借鉴其"全屏图标网格、文件夹、搜索"的交互形态。
- 差异点：① 不只启动本地应用，还支持**插件图标与小组件**（时钟、天气、设备控制等）同屏混排；② 跨三平台（Win/macOS/Linux）；③ 极简轻量（安装包 < 15MB、秒开）。

## 2. 目标用户与场景

| 画像 | 痛点 | 使用场景 |
|---|---|---|
| 效率型桌面用户 | 桌面堆满快捷方式、开始菜单查找慢 | 热键唤起启动器，网格点选/搜索快速打开应用与文件夹 |
| 桌面定制用户 | 想要手机式自定义桌面体验 | 一张桌面上混排图标与小组件（时钟/天气等），多页、文件夹、拖拽排序 |
| 折腾型用户（本项目的直接使用者） | 手机桌面玩腻了，想在电脑上也这样 | 自定义图标、分组、拖拽排序、添加自己写的插件/小组件 |

## 3. 核心功能列表（MVP 范围）

| 功能 | 优先级 | 说明 |
|---|---|---|
| 手机式桌面（图标网格） | P0 | 窗口/全屏均可；图标与小组件**同屏混排**，可多页 |
| 插件机制：图标/小组件注册 | P0 | 插件声明清单 → 注册图标或小组件到桌面；内置"应用启动"与"自定义命令"两类基础图标 |
| 小组件（时钟/天气等） | P0 | 插件贡献小组件，直接在桌面上渲染（2x1 等网格占位） |
| 文件夹分组 | P0 | 图标可拖入文件夹；文件夹内再展开为网格 |
| 布局持久化 | P0 | 图标位置/小组件/分组/页面配置保存到本地，重启不丢失 |
| 搜索 | P0 | 输入即过滤图标/小组件（模糊匹配名称） |
| 添加/删除图标与小组件 | P0 | 从"所有应用"列表添加；悬停删除 |
| 拖拽排序 | P1 | 网格内拖拽调整位置，拖到文件夹/页面边缘翻页 |
| 热键唤起 | P1 | 全局快捷键打开/关闭启动器 |
| 外观自定义 | P2 | 壁纸/背景图、图标大小、网格密度 |
| 插件市场 | P2 | 从本地目录安装插件包（zip + manifest） |
| 主题 | P2 | 浅色/深色/跟随系统 |
| **Launchpad 全屏 Pad** | P1 | **（2026-02-13 新增，形态已确认）** 同一张桌面铺满全屏（图标+小组件+文件夹+多页）；全局快捷键 = Pad 开关（按一下出现、再按消失）；顶栏 ⛶ 窗口⇄全屏、记忆上次状态、Esc 退出；规划为 M6 |
| **可配置全局快捷键** | P1 | **（2026-02-13 新增，范围已确认）** "显示/隐藏 Pad"快捷键可配置（默认 Alt+Space 兜底）；设置面板录入、冲突提示、持久化；不做图标级快捷键；规划为 M7 |

**MVP（P0）交付物**：手机式桌面（图标 + 小组件混排）+ 插件注册机制 + 文件夹 + 多页 + 搜索 + 持久化。

| 类别 | 要求 | 可验证指标 |

| 轻量 | 安装包 ≤ 15MB；常驻内存 ≤ 200MB | 打包后实测 |

## 6. 验收标准（P0 每项可测）

1. **网格渲染**：应用启动后 ≤2s 出现桌面网格；100 个图标下滚动/翻页流畅（≥30fps）。
2. **插件注册**：放置一个符合 schema 的插件目录后，重启应用其图标出现在网格中；插件清单校验失败时给出提示且不影响应用运行。
3. **文件夹**：可创建文件夹、将 ≥2 个图标放入；文件夹展开/收起正常，配置持久化。
4. **小组件混排**：添加时钟/天气小组件后，在桌面上以 2x1 等尺寸实时渲染，与其他图标同屏混排。
5. **搜索**：输入子串可过滤出匹配图标/小组件；清空恢复全部。
6. **持久化**：调整布局 → 重启应用 → 布局完全恢复。
7. **三平台构建**：在 Windows 上 `cargo tauri build` 成功产出安装包（macOS/Linux 留 CI 验证）。
