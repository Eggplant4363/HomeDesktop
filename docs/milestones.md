## M6 — Launchpad 全屏 Pad（2026-02-13 用户提出；形态已确认：同一张桌面铺满全屏）

> 用户语义（2026-02-13 确认）：**按一下快捷键 → 全屏"Pad"出现（整个屏幕就是桌面）；再按一下 → Pad 消失**（类似 Launchpad）。全屏不是独立视图，就是同一张手机式桌面铺满屏幕。

- **范围**：
  - **全屏 Pad**：窗口铺满屏幕（无边框沉浸），图标/小组件/文件夹/多页照常；网格 `auto-fill` 按固定 tileSize → 全屏自动多列；图标大小沿用外观设置。
  - **全局快捷键 = Pad 开关**（默认 Alt+Space，M7 做可配置）：窗口隐藏 → 显示并进全屏；全屏中 → 隐藏（Pad 消失）；窗口模式中 → 进全屏。
  - **顶栏按钮 ⛶**：窗口模式 ⇄ 全屏 Pad（窗口保持可见，不隐藏）。
  - **记忆上次状态**：退出/切换时把"是否全屏"写入配置；启动时若上次为全屏 → 直接进全屏 Pad。
  - **Esc**：全屏中按 Esc → 退出全屏回窗口模式（自然收尾）。
  - 顶栏在全屏下保留（搜索/编辑/设置 + ⛶ 回窗口）。
- **技术要点**：Tauri `WebviewWindow::set_fullscreen(bool)`；配置键 `ui.fullscreen`（config.json）；快捷键行为在 `lib.rs` 的 global-shortcut handler 中实现（显示/隐藏逻辑改造）。
- **Done 标准**：快捷键 Pad 开/关正常（进入全屏/隐藏）；⛶ 窗口⇄全屏正常；启动记忆生效；Esc 退出全屏；全屏下布局/搜索/编辑/设置完整可用；svelte-check 0 警告、前端测试通过。

## M7 — 可配置全局快捷键（2026-02-13 用户提出；范围已确认：仅 Pad 开关一项，不做图标级快捷键）

- **范围**：把写死的 Alt+Space 升级为**可配置**（默认 Alt+Space 兜底）；设置面板新增「快捷键」区块，录入"显示/隐藏 Pad"组合键；冲突提示（同一键被占用时拒绝并提示）；持久化到 config.json（`shortcuts.togglePad`）；重启恢复。
- **明确不做**（用户 2026-02-13 确认）：不给每个图标/小组件配启动快捷键；暂不扩展翻页/搜索聚焦等其他动作（框架留好扩展位即可）。
- **技术要点**：`tauri-plugin-global-shortcut` 动态管理——配置变更时 `unregister` 旧键 → `register` 新键 → 立即生效；前端录入用 keydown 捕获修饰键组合。
- **Done 标准**：设置里修改快捷键立即生效、重启保持；默认 Alt+Space；冲突提示；前端测试通过。

## M8 — 文件夹交互补全（规划中，2026-02-13 用户选定）

- **Done 标准**：文件夹内可拖拽排序且持久化；重命名/换 emoji 生效；前端测试通过。

## M9 — 图标自定义（规划中，2026-02-13 用户选定）

- **范围**：编辑模式对图标**重命名 / 换 emoji / 换颜色 / 换成系统应用图标**（真实图标，复用 app_icon）。
- **技术要点**：IconCell 增加可选字段（`emoji?/color?`），**Rust Cell/IconItem 同步加可选字段**（否则 serde 往返会丢字段）；图标渲染优先自定义 emoji/颜色，其次系统图标/插件 emoji。
- **Done 标准**：图标可重命名/换 emoji/换颜色/换系统图标并持久化（layout 往返不丢字段）；core + 前端测试通过。

## M10 — 全局搜索面板（规划中，2026-02-13 用户选定）

- **Done 标准**：快捷键唤起/关闭；三类结果可搜、回车启动；前端测试通过。

- **Done 标准**：卸载后插件从桌面/列表消失且布局不崩；更新覆盖生效；core 测试通过。
